# Bijdragen aan Pylades

Welkom. Dit project bestaat dankzij mensen die hun tijd, kennis en ervaring delen. Hieronder lees je hoe je kunt meedoen.

## Wie kan bijdragen

Iedereen die zich kan vinden in de doelen en spelregels van dit project. Je bijdrage kan bestaan uit:

- Broncode (nieuwe functionaliteit, bugfixes, refactoring)
- Domeinkennis in de vorm van templates
- Fictieve testdata
- Documentatie en voorbeelden
- Vertalingen
- Het melden van issues en het bespreken van ideeën

## Wie kan de software gebruiken

De software is bedoeld voor niet-commercieel gebruik. Specifiek welkom zijn:

- Medische instellingen zoals ziekenhuizen
- Onderwijsinstellingen
- Onderzoeksorganisaties
- Liefdadigheidsinstellingen
- Overheidsinstellingen

Voor commerciële zorgleveranciers of softwareleveranciers die de software willen integreren in hun product geldt deze licentie niet automatisch. Neem in dat geval contact op.

## Hoe je bijdraagt

1. Open een issue om je idee of probleem te bespreken, of reageer op een bestaand issue
2. Fork de repository naar je eigen GitHub-account
3. Maak een feature branch met een beschrijvende naam
4. Commit je wijzigingen in kleine, logische stappen
5. Open een pull request naar de hoofdtak

Bij je eerste pull request ontvang je een verzoek om de Contributor License Agreement te accepteren via CLA Assistant. Dit gebeurt met één klik en geldt voor al je toekomstige bijdragen aan dit project.

## Wat we van een bijdrage verwachten

- Code volgt de stijlgids van het project (zie `STYLE.md` indien aanwezig)
- Pull requests bevatten een korte uitleg van wat en waarom
- Wijzigingen aan publieke interfaces gaan vergezeld van bijgewerkte documentatie
- Nieuwe functionaliteit komt met tests
- Templates en testdata zijn fictief en bevatten geen herleidbare persoonsgegevens

## Toon en samenwerking

We gaan respectvol met elkaar om. Directheid is welkom, neerbuigendheid niet. Bij twijfel: ga uit van goede bedoelingen en stel een verhelderende vraag.

## Ondersteuning leveren

Naast bijdragen aan de software kun je ook ondersteuning bieden aan gebruikers. Dit kan om niet of tegen vergoeding. Geef in je profiel of in een aparte `SUPPORTERS.md` aan welke ondersteuning je biedt en onder welke voorwaarden.

## Contact

Vragen? Open een issue of stuur een bericht via GitHub.

## Toekomstige stichting

Zodra het project levensvatbaar blijkt, brengen de oprichters de rechten onder in een stichting met als doel het beheer en de doorontwikkeling van deze software. Door de CLA te accepteren stem je toe dat je bijdrage onder dezelfde voorwaarden bij die stichting belandt. Meer details staan in `CLA.md`.
